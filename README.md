# عالطريق — MVP للويب

> مو تطبيق تذكير. تطبيق يجاوب على سؤال واحد: **هل يستاهل أوقف الحين؟**

نسخة ويب قابلة للاستخدام والتجربة من الـ MVP الموصوف في خطة المنتج: تكتب التذكير بالعربي، وإحنا ننبهك
وأنت تسوق **بس** لما يكون المكان قدامك على طريقك، والتحويلة (الوقت الإضافي الحقيقي) تحت الحد اللي حددته.

الموقع RTL، مبني للجوال أول، ويشتغل كـ PWA (تقدر تضيفه للشاشة الرئيسية).

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # اختبارات المحرك (٣٢ اختبار)
npm run build    # ينتج dist/ جاهز للنشر على أي استضافة ثابتة
npm run icons    # يعيد توليد أيقونات PNG من نفس تصميم icon.svg
```

## جرّبه بدون ما تسوق

افتح تبويب **المشوار** ← «محاكاة مشوار» ← اختر مسارًا في الرياض ← سرعة ×5 أو ×10 ← شغّل.
المحاكاة تجيب مسارًا حقيقيًا من OSRM وتمشي عليه بسرعات كل مقطع، والأماكن حقيقية من OpenStreetMap.
كل قرار (نبّه / ما نبّه / مرّينا بدون تنبيه) ينحفظ في تبويب **السجل** مع سببه.

## الفرق الجوهري عن خطة iOS

المتصفح ما يعطيك تتبع موقع في الخلفية ولا geofencing يوقظ التطبيق. يعني:

- نسخة الويب تشتغل **والصفحة مفتوحة** (خلّ الجوال على الحامل، ونبقي الشاشة شغالة بـ Wake Lock).
- التذكير بالوقت يشتغل بس والصفحة مفتوحة.
- ما فيه تدوير geofences ولا حد الـ ٢٠ منطقة، لأن ما فيه geofence أصلًا: نحسب القرب محليًا من كل عينة GPS.

كل الباقي (المنطق، العتبات، النصوص، تجربة المستخدم، مقاييس البيتا) قابل للنقل حرفيًا للتطبيق الأصلي،
لأن الجزء الحسّاس كله في `src/core/` بدون أي اعتماد على المتصفح.

## الخريطة السريعة للكود

```
src/core/      منطق صافي ومختبَر: التطبيع العربي، المحلل، الوقت، الهندسة، التحويلة، البوابة، النصوص
src/services/  الربط بالعالم: OSM/OSRM/Nominatim، الكاش، الجهاز (صوت/نطق/إشعارات)، المحاكي، المحرك
src/state/     التخزين على الجهاز (localStorage) + سجل القرارات
src/ui/        الواجهات: اليوم، المشوار (خريطة Leaflet)، السجل، الإعدادات، الترحيب، لوحة التنبيه
```

نقطة البداية لفهم المنتج: `src/services/engine.ts` → `checkPassBy()`.

## مصادر البيانات والخصوصية

- التذاكير والسجل والإعدادات كلها في `localStorage` على الجهاز. ما فيه حساب ولا سيرفر لنا.
- الأماكن: **Overpass API** (OpenStreetMap). المسارات والتحويلة: **OSRM** التجريبي. البحث بالاسم: **Nominatim**.
  هذي خوادم مجتمعية بسياسة استخدام عادل — تصلح للتجربة والبيتا الصغيرة، **مو** للإطلاق.
  قبل أي إطلاق: استضافة OSRM خاصة (أو مزود مدفوع) + مفتاح خرائط للبلاطات.
- وقت البحث عن الأماكن أو حساب المسار نرسل إحداثياتك لهذي الخدمات. مذكور صراحة في شاشة الإعدادات.

## عتبات تستاهل الضبط بعد أول بيانات حقيقية

الافتراضات في `src/core/types.ts` (`DEFAULT_SETTINGS`) وفي `src/core/detour.ts`:

- `maxDetourMin: 3` — الحد الأقصى للتحويلة.
- `outerRingM: 1800` — متى نبدأ نقيّم مكانًا.
- `aheadAngleDeg: 60` — متى نعتبره «قدامك».
- `SIDE_SPEED_MS` (٣٠ كم/س) — السرعة المفترضة للتحويلات والشوارع الجانبية.
- قاعدة الـ U-turn في `estimateDetour`: لو الطريق للمكان ملتف، نفترض الرجعة ملتفة مثله.

السجل + مقاييس البيتا الثلاثة هما أداة الضبط: شغّل مشاوير حقيقية، وراجع «ليش ما نبهني».
